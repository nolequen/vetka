# Vetka 0.2.0 – чек-лист для портала Unity China Asset Store

Портал: https://assetstore.u3d.cn/publisher-portal. Заполняет и отправляет автор; тексты полей берутся из
`listing-zh.md` этой папки (раздел с тем же названием, без строк «Обратный перевод»). Названия полей взяты из
руководства Tuanjie «Publishing to the Asset Store» и в самом портале могут звучать иначе: ориентир – порядок и
смысл.

## 1. Профиль издателя (один раз)

- [ ] Publisher name: как на глобальном сторе.
- [ ] Website: https://upwake.dev
- [ ] Support email: vetka@upwake.dev
- [ ] Country: страна налогового резидентства. **Потом её не поменять.**
- [ ] Проверка личности по паспорту, если портал её запросит.
- [ ] Платёжные данные (PayPal или банк) можно заполнить позже: Vetka бесплатна, выплат по ней не будет.

## 2. Черновик пакета

- [ ] Создать новый пакет (draft), категория **Tools → Version Control**.
- [ ] Цена: **бесплатно**.
- [ ] «Также опубликован в Unity Asset Store»: **нет** (глобальная 0.1.0 ещё на проверке).
- [ ] Версия: **0.2.0**. Если портал требует 1.0.0 для нового пакета, спросить у Claude, прежде чем менять.

## 3. Package Upload

- [ ] Файл: `store\releases\vetka-0.2.0-tuanjie.unitypackage` (114 КБ, `Assets/Vetka`, без зависимостей).
- [ ] Минимальная версия редактора: **Tuanjie 1.6** (так советовала поддержка 23 октября).
- [ ] Совместимость с конвейерами рендеринга: отметить **все три** (Built-in, URP, HDRP) – Vetka работает только в
  редакторе.

- [ ] После вставки сверить, что в тексте нет строк «Обратный перевод».
